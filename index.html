재고 마스터 시트 연동

설정 방법
  1. COVE 입출고 관리 대장 구글 시트 열기
  2. 확장 프로그램 → Apps Script
  3. 아래 "재고 시트 Apps Script 코드" 전체 복사 → 붙여넣기 → 저장
  4. 배포 → 새 배포 → 웹 앱
    실행 계정: 나 / 액세스: 모든 사용자
  5. 웹앱 URL 복사 → 위 입력란에 붙여넣기
동작 방식: 앱 실행 시 "COVE 통합" 요약 탭에서 품목·재고·바코드를 불러오고,
입/출고 처리 시 요약 탭 재고와 품목별 개별 탭에 거래 내역이 자동 기록됩니다.
판매가·VAT·수수료 등 회계 열은 자동으로 채우지 않으니 별도로 확인해 주세요.

재고 시트 Apps Script 코드

판매보고서 시트 연동 (참조·엑셀용)

설정 방법
  1. COVE 월별판매보고서 구글 시트 열기
  2. 확장 프로그램 → Apps Script
  3. 아래 코드 전체 복사 → 붙여넣기 → 저장
  4. 배포 → 새 배포 → 웹 앱
    실행 계정: 나 / 액세스: 모든 사용자
  5. 웹앱 URL 복사 → 위 입력란에 붙여넣기
동작 방식: 바코드 스캔 → 출고(판매) 처리 시
해당 월 시트(예: 26.05)에 날짜·품목·수량·금액이 자동 기록됩니다.
이 시트는 재고 마스터로 쓰지 않고, 엑셀 다운로드·과거 데이터 참조용으로만 사용됩니다.
